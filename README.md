
# 🚌 BusTrack

### Smart Transit • Real-Time Occupancy Monitoring

BusTrack is a web-based smart transit monitoring project that displays bus occupancy, available seats, simulated GPS locations, and route information.

## 🚀 Live Demo

[View BusTrack Live Website](https://zohaaf04-a11y.github.io/BusTrack/)

## ✨ Features

- 🚌 Select between multiple buses
- 👥 Track passenger occupancy
- 💺 Display available seats
- 📊 Visual occupancy progress bar
- 📍 Simulated GPS location updates
- 🗺️ Interactive route visualization
- 📱 Responsive design for mobile and desktop
- 🎨 Modern UI with animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- TensorFlow.js
- COCO-SSD
- Git and GitHub

## 📌 Project Note

This is an academic demonstration project. GPS tracking is simulated using predefined routes and does not represent real-time physical bus tracking.
